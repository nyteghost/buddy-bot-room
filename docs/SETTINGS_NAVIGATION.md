# Find your way around Pixel Pals Settings

Settings opens one category at a time instead of showing every service in a long vertical stack.

1. Use Find a setting to search by service name, setting name, or explanation. Saved passwords and private links are never searched.
2. Pick a category in the left navigation (scrollable horizontally on mobile).
3. Use All, Connected, or Not set up to narrow the list.
4. Select Edit or Set up for one service. Use Test for a single service or Check connections for all connected services.
5. Use Show details for the screenshot-privacy toggle. Each individual setting has a collapsible explanation.

Quick locations: Discord Companion is under Phone & reminders; Calendar feeds is under Calendar & mail; Ollama is under Basics; Obsidian is under Home & server; backup controls are under Backups & schedules.

The UI does not clear existing values. Server credentials remain write-only in private storage. Docker environment overrides remain available. Add-ons have their own category.

Deep links from other parts of Pixel Pals open the matching category. If nothing matches, clear the search or switch to All.
